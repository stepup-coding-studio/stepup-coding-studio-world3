WORLD 3 : DINOSAUR ESCAPE V6

ปรับตามที่อนุมัติ:
- เพิ่มปุ่ม “สุ่มด่าน” สำหรับครูที่แถบด้านบน
- ครูกดสุ่มด่านได้ตลอดเวลา จากโจทย์ทั้งหมด 20 ด่าน
- เมื่อสุ่ม โปรแกรมใน Coding Area จะถูกล้างและโหลดโจทย์ใหม่
- ขยายลูกศรใน Command Palette
- ปรับปุ่มคำสั่งด้านขวาให้ใหญ่และสมดุล
- ขยับ Game Board ขึ้นและเว้นระยะจาก Coding Area
- ปรับขนาดไอคอนค่าย เด็ก ไข่ ฟอสซิล หิน และภูเขาไฟให้สมดุล
- เอาเส้นใน Coding Area ออกทั้งหมด
- ขยับ RUN / Undo / ล้าง / คำใบ้ขึ้นและเพิ่มขนาด
- คงหน้า Home ที่อนุมัติ ระบบสุ่มตอนเริ่มเกม และความรู้วิทยาศาสตร์เดิม
